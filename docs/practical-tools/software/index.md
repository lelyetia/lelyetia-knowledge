# 软件<sup>*</sup>

本栏目整理磁盘迁移、分区管理与启动盘制作相关的软件。标题上的上标 * 表示由 AI 整理的资料笔记，可作为后续学习与实操记录的索引。

## 软件索引

| 软件 | 主要用途 | 适用场景 |
| --- | --- | --- |
| [Clonezilla（再生龙）](clonezilla.md) | 整盘或分区克隆、镜像备份与还原 | 更换硬盘、迁移已有系统与数据 |
| [GParted](gparted.md) | 创建、调整、移动与检查分区 | 整理磁盘布局、为 Windows 预留空间、管理已识别的 RAID 逻辑磁盘分区 |
| [Rufus](rufus.md) | 将系统或 Live 镜像写入 USB 启动盘 | 准备安装、克隆与分区维护所需的启动环境 |

## 如何配合使用

在 Windows 电脑上用 Rufus 制作相应的启动盘，再从启动盘进入 Clonezilla 或 GParted Live。迁移已有系统时选择 Clonezilla，调整磁盘空间与分区布局时选择 GParted。三者分别处理启动介质、磁盘数据复制和分区布局。

涉及已有数据的操作，先确认备份可用，再核对目标设备的型号、容量及分区。具体步骤和适用条件见各篇笔记。
