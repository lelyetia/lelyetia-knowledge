## 介绍

《机器学习》（俗称“西瓜书”）是由南京大学周志华教授编著的经典机器学习入门教材。因其封面采用了绿色的西瓜图案而得名。本书将不涉及任何代码有关的工程知识，而是专注于机器学习的理论公式。
书籍中涉及的内容有：

1. 模型的评估和选择
2. 线性模型
3. 决策树
4. 神经网络
5. 支持向量机
6. 贝叶斯分类器
7. EM算法
8. 集成学习
9. 聚类
10. 降维与度量学习
11. 特征选择与稀疏学习
12. 计算学习理论
13. 半监督学习
14. 概率图模型
15. 强化学习

《南瓜书》则是由Datawhale发起的开源项目，针对西瓜书中的公式推导进行了详细的解析和补充，可在 [南瓜书官方GitHub](https://github.com/datawhalechina/pumpkin-book) 查看[^南瓜书]。注意：南瓜书并不是西瓜书的官方配套教材，而是由社区发起的扩展版本，可以理解为DLC。
